## 核心结论

1. **最合适的已测 LR 与动量有关。** 原配置下，MCSD/MCSD-TP 的最优已测 LR 为 `0.010`，MuonH/NorMuon-Sphere 为 `0.015`。统一 `beta=0.9 EMA` 后，MCSD 两组最优已测 LR 移到 `0.012`，基线为 `0.015`。
2. **两种 EMA 对照都保留基线优势。** 在 `beta=0.9 EMA, LR=0.010` 下，MCSD 为 3.473145，MuonH 为 3.471362，NorMuon 为 3.470496；新补齐的 0.95 EMA 对照也得到同样的排序。
3. **两个 seed 下，冻结配置的基线排序保持。** NorMuon-Sphere 与 MuonH 的平均最终 loss 更低；MCSD 与 MCSD-TP 差距很小，二者顺序随 seed 改变。
4. **增加到 6B 尚未证明 MCSD 能反超。** seed=1234 最终 MCSD 为 3.431077，NorMuon 为 3.426804，差值 0.004273；seed=2026 尚在运行，同 step12600 仍是 NorMuon 更低。
5. **unit-F 归一化尚无稳定收益。** 在 MCSD 常用 LR=0.010/0.012 上未改善；LR=0.020 的小幅改善也没有超过常规 MCSD 的最佳配置。

这些是有限网格与少量 seed 的观察，不代表全局最优超参数、统计显著性或 scaling law。

验证迭代器会推进，曲线比较应对齐同一 seed 的相同步数。改变 seed 可能同时改变初始化和数据顺序。
3B 与 6B 的 cosine 总时长不同，二者同一中间 token 数的差异不能单独归因于“多训练数据”。

**命名约定。** 本文 Nesterov 指 Muon-style 梯度组合：

```text
M_t = beta * M_(t-1) + (1-beta) * G_t
EMA:       S_t = M_t
Nesterov:  S_t = beta * M_t + (1-beta) * G_t
```

真实流形点外推（在新的外推点计算梯度）只做过本地小问题，尚无 LLM 主实验。
MCSD-unitF 是独立消融；基线自身的方向归一化仍保留，不能由额外开关 `direction_normalization=none` 推断基线未归一化。
