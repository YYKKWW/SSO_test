# MCSD-TP / MCSD–P²GD 实验结果汇总

更新：2026-10-28。范围：近期 **width-256 的 12 组 1B + 6 组 3B** 对照；全部完成，无已记录的 NaN/skipped iteration。3B 最后远端核实时间为 **2026-10-27 23:50 HKT**。

本页集中汇总结果，不与历史论文的 width-256/512/1024、top-8 MCSD-PGD 或旧 12B 实验混合。当前混合方法是**近顶部簇 P²GD 型方向 + 近似径向返回**，不是 full-SVD PGD，也不是已证明收敛的标准 P²GD。

## 结论先看

- **下一轮优先候选：K10/c8 混合。** 3B 最终 loss 为 **3.442441**，比匹配 MCSD-TP K10 降低 **0.001502**；比 K20 混合更好，并节省约 41 分钟。
- **仍未超过基线。** 同轮 MuonSphere / SSO 为 **3.442197 / 3.442296**，K10 混合分别高 **0.000244 / 0.000145**。均为单 seed，不能宣称显著优势或等效。
- **已避免训练更新中的原矩阵 full SVD。** 四组 3B 实验算法仅调用小 Ritz SVD；K10 混合比 MuonSphere 慢 **6.30%**、比 SSO 快 **4.34%**。
- **仍有工程限制。** K10 启动谱误差较大；两组混合约 57%–59% 的簇调用是连续重复，且存在 top-4 容量溢出。

## 1. 比较口径

| 项目 | 设置 |
|---|---|
| 模型 | width=256，28 层，FFN=768，head dimension=128 |
| 训练 | sequence length=4096，global batch=128，microbatch=4，seed=1234，每组一张 H20 |
| 数据 | 同一份 3B indexed OLMo 数据源；1B/3B 指本轮处理预算 |
| 精度 | BF16 模型/矩阵符号计算，FP32 主权重及实验算法的 QR/Ritz |
| 调度 | 250 warmup steps，cosine 衰减到峰值 LR 的 10%；均从头训练 |
| 1B | 1908 steps，每次验证 5 batches |
| 3B | 5723 steps，每次验证 20 batches |
| 指标 | 最终验证 loss，不选训练过程最小值；耗时含训练和验证，不含预检及离线审计 |

1B 与 3B 的验证批数和学习率调度长度不同，不把两轮 loss 直接拼成同一评估曲线。

| 方法 | 本轮实际实现 |
|---|---|
| MuonSphere | 任务名 `muon_ball_dist`，参考 BF16 PI10 / NS8 路径 |
| SSO | 任务名 `spectral_ball_dist`，参考 PI10 / NS8 与乘子求解路径 |
| MCSD-TP | 缓存顶部向量构造切向方向，矩阵符号后再次切向修正，近似径向返回；不切换簇分支 |
| MCSD–P²GD 型混合 | 与 control 共用 MCSD 路径；小 gap 时切换到归一化动量的近顶部簇方向；两分支共用返回与谱缓存 |

实验算法固定 warm block-8、FP32 QR/Ritz、`gap=5e-5`、簇阈值 `2e-3`、自适应 top≤4。`K` 是子空间迭代次数；`c` 仅缩放簇分支步长，**不是簇使用比例**。簇分支先做 Frobenius 动量归一化，不做投影后归一化或 MCSD 长度匹配。约束矩阵 weight decay 为零。在线没有误差门控或自动 full-SVD fallback。

## 4. 分支与精度诊断

以下为 3B 混合方案。分支统计到 step5720，分母均为 1,441,440 次组件调用，含 252 次零学习率初始化；不是训练步数。

| 指标 | K10/c8 | K20/c8 |
|---|---:|---:|
| 累计簇调用 | 25,681（1.7816%） | 25,490（1.7684%） |
| step5720 单步簇比例 | 10.32% | 13.10% |
| 连续重复比例 / 平均连续长度 | 57.30% / 2.34 | 58.69% / 2.42 |
| 超过 top-4 容量 | 2,952 | 2,931 |
| 抽样平均绝对 gap 误差 | `1.014e-4` | `4.345e-6` |
| 抽样绝对 gap 误差中位数 | `1.044e-6` | `7.694e-7` |
| 最大抽样返回半径相对误差 | `1.038e-4` | `2.849e-5` |
| 抽样 false-safe / false-cluster | 0 / 0 | 0 / 0 |

每组混合仅审计 52 个有选择的样本，不能据此保证全程零误判。K10 的误差总和约 96.1% 来自 step2 的四个启动样本；其余 48 个样本平均 gap 误差为 `4.294e-6`，但这不替代全部样本的统计。top-4 溢出意味着不能宣称完整真实切锥处理。

每组 3B 实验算法完成 1,442,196 次小 Ritz SVD，更新中的原矩阵 full SVD / svdvals 为零；精确分解仅用于测试和训练后审计。基线未接入此计数器。

## 5. 后续优先级

1. **先复测稳定性：** K10/c8、匹配 K10 control、MuonSphere、SSO 增加第二个 seed。
2. **再隔离启动误差：** 比较固定 K10 与启动阶段 K20、随后 K10；其余参数不变。
3. **最后检查簇容量：** 同一 K10/gap/c 下比较 top≤4 与 top≤8，重点看后期 loss、重复调用和成本。

以上是建议，尚未因本次文档整理提交新任务。K10/c8 是当前优先候选，不是已确认的普适最优参数；没有跨 width 或理论收敛保证。
